# 🐾 PetLove — Pet Care Web Application

A responsive user registration and management module built with Next.js (App
Router, Server Actions), Tailwind CSS, React Hook Form, and Yup validation.

🚧 **Status:** _Work in Progress (WIP)_

🔗 **Live Demo:**
[View on Vercel](https://petlove-next-pet-project-zhbm-roan.vercel.app/)

## 🚀 Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/AnnVynnychenko/petlove-next-pet-project.git

# 2. Install dependencies
npm install

# 3. Create .env.local in the root directory and add:
# API_URL=https://petlove.b.goit.study/api

# 4. Run the development server
npm run dev
```
